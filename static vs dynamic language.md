# Static vs Dynamic Languages



#### Static Languages:

---Variable types are determined at compile time.

---Examples: C, C++, Java, Rust.

---Variables must be declared with a type before compilation.

---If you assign the wrong type, the compiler throws an error before the program runs.

---Types are strictly enforced and cannot change once declared.

---Advantages: errors caught early, faster performance, strong type safety.

---Disadvantages: less flexible, more verbose code.



#### Dynamic Languages:

---Variable types are determined at runtime.

---Examples: Python, JavaScript, Ruby.

---No need to declare types explicitly; the interpreter decides at runtime.

---Errors (like type mismatches) only appear when the program is executed.

---Variables are flexible and can change type during execution.

---Advantages: easier and faster to write code, great for rapid prototyping.

---Disadvantages: errors may only show up while running, slower performance.
